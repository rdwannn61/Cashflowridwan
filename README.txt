CASHFLOW PERSONAL — PWA
Unggah semua isi folder ini ke root repository GitHub (jangan unggah ZIP-nya).
Pastikan index.html, manifest.webmanifest, dan sw.js berada di root.
Folder icons berisi icon-192.png dan icon-512.png.

Aktifkan GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root) > Save.
Tunggu deployment selesai, lalu buka URL Pages di Chrome Android.
Menu Chrome (⋮) > Install app / Tambahkan ke layar utama.

Data transaksi tersimpan pada browser di alamat GitHub Pages. Jangan hapus data situs/browser.
Gunakan Ekspor CSV untuk membuat cadangan transaksi.
